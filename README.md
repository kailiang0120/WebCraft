# WebCraft — 网页版我的世界

用 **Three.js / WebGL** 和原生 Web 技术实现的浏览器体素沙盒游戏。所有贴图、图标和音效都由代码程序化生成，不依赖任何外部素材。

## 运行

```bash
npm install
npm run dev      # 开发服务器 http://localhost:5173
npm run build    # 生产构建到 dist/
```

## 功能

- **地形生成**：Simplex 噪声 + 分形布朗运动；大陆/山脉/细节多层高度图
- **生物群系**：平原、森林、沙漠、雪原、山地、沙滩、海洋（温度 + 湿度噪声）
- **洞穴与矿石**：3D 噪声“蠕虫”洞穴 + 地下大洞穴；煤、铁、金、钻石矿脉按深度分布
- **植被**：橡树、云杉（可跨区块边界）、草、花、仙人掌
- **合成系统**：背包 2×2 合成、工作台 3×3 合成，支持有序/无序/镜像配方，Shift 一键合成
- **工作台方块**：工作台、熔炉（燃料 + 冶炼进度）、箱子（27 格存储）
- **工具**：木/石/铁/金/钻石 × 镐/斧/锹/剑，挖掘速度、采集等级和耐久度遵循原版公式
- **光照**：顶点环境光遮蔽（AO）、平滑光照、昼夜循环
  - 天空光：直射到第一个不透明方块，再向侧面/洞口内逐格衰减扩散，屋檐下和洞口呈自然渐变阴影
  - 树叶和水每格额外削弱 1 级光：树荫下更暗、深水越深越暗
  - 方块光：火把、幽光灯、火、岩浆、燃烧中的熔炉按 Minecraft 规则泛洪传播（每格衰减 1 级），**墙会挡光**
  - 动态光：手持火把、幽光灵每帧在玩家周围 32³ 区域做泛洪计算，上传为 3D 纹理供着色器采样，同样被墙阻挡
- **流动的水**：与 Minecraft 相同的规则——水源向四周流 7 格、优先流向 4 格内最近的落差、遇到落差向下流、两个水源之间生成新水源；移除水源后流水会逐渐退去；水流会推动玩家、生物和掉落物，冲走花草和火把；水面按水位倾斜显示；水和岩浆贴图会流动
- **岩浆**：部分深层大洞穴（y ≤ 10）的底部是岩浆湖（约四分之一的区块有）；岩浆流得慢（1.5 秒一次）、只流 3 格，自身发光；碰到会掉血并着火（离开后继续燃烧，跳进水里熄灭），掉落物会被烧毁；岩浆会不时点燃附近的木头、树叶等可燃物
  - 水碰到岩浆源 → 黑曜石；碰到流动岩浆 → 圆石；岩浆流到水上 → 石头。黑曜石需要钻石镐挖
- **火**：与 Minecraft 相同的蔓延规则——每 1.5~2 秒燃烧一次，按方块的“可燃性/助燃性”把木板、原木、树叶、羊毛、草烧掉并向周围空气蔓延；没有可燃物的火会自己熄灭；火会发光、点燃玩家和生物；左键点火焰所在的方块面可以灭火；水流过会浇灭
  - 着火死掉的动物直接掉熟肉
  - **火焰质感**：火焰贴图实时生成（约 20 帧/秒），是一条条摇曳、窜高的火舌，颜色从白黄的焰心到橙色再到红色焰尖，飘起的火苗会断开、消散；地面上的火由两组交叉、向外倾斜的火片组成（1.4 格高），贴着可燃墙壁的火会附在墙面上，和原版模型一致
  - **粒子**：火冒浓黑烟，火把和燃烧的熔炉有小火苗和细烟，岩浆表面不时溅出发光的火星（落下时拖着烟），打火石点火会迸出火花，灭火、岩浆遇水、爆炸都会冒烟
  - **声音**：火的噼啪声、岩浆的“啵”声和低沉的冒泡声（随距离衰减）
  - **着火的生物**全身被火焰包裹；玩家着火时屏幕底部两侧有动态火焰（与原版第一人称相同）
  - 岩浆和水的贴图可以无缝拼接，熔炉燃烧时炉口火光会闪动
- **打火石**：铁锭 + 燧石，点火（64 次耐久）
- **TNT**：火药 + 沙子，用打火石、火或爆炸点燃，闪烁 4 秒后爆炸（威力 4，比苦力怕大）；爆炸会连锁引爆附近的 TNT、把掉落物和 TNT 炸飞；在水里爆炸不破坏方块
- **盔甲**：皮革/铁/金/钻石 × 头盔/胸甲/护腿/靴子，护甲值、耐久和减伤公式与原版相同（钻石有韧性，扛大伤害更强）；摔落、饥饿、身上着火的伤害不受盔甲影响；每次受击盔甲掉耐久；背包左侧 4 格穿戴，也可以手持右键直接穿上；护甲值显示在血条上方
- **铁桶**：3 个铁锭 V 字形合成；可以装水、装岩浆；岩浆桶是最强的熔炉燃料（烧 100 个物品，烧完返还空桶）
- **多线程**：地形生成和「光照计算 + 区块网格构建」都在 Web Worker 中进行，主线程每帧只做轻量工作，挖方块、加载区块不卡顿
- **掉落物**：挖方块、打生物、爆炸、箱子/熔炉被拆都会在地上生成掉落物（旋转、上下浮动、相同物品自动合并），靠近自动吸取；背包满了物品会留在地上，不会丢失；Q 键扔出物品，背包界面外点击也可扔出
- **物理**：AABB 碰撞、重力、跳跃、疾跑、潜行防坠落、游泳、摔落伤害、生命恢复
- **生存 / 创造模式**：创造模式下可飞行、瞬间破坏、物品栏无限取用
- **其他**：沙子/沙砾重力下落、方块破坏粒子、挖掘裂纹、第一人称手持物品、云和星空

### 生物系统

| 生物 | 类型 | 行为 | 掉落 |
| --- | --- | --- | --- |
| 猪 / 牛 / 羊 / 鸡 | 友好 | 白天在草地成群生成，闲逛，被打会逃跑 | 生肉、皮革、羊毛、羽毛 |
| 僵尸 | 敌对 | 追击近战，白天在阳光下燃烧 | 腐肉 |
| 骷髅 | 敌对 | 保持距离、绕圈走位、射箭 | 骨头、箭 |
| 苦力怕 | 敌对 | 靠近后嘶嘶作响，1.5 秒后爆炸（破坏方块） | 火药 |
| 蜘蛛 | 敌对 | 速度快、会爬墙、会扑击 | 线 |
| **岩傀**（原创） | 敌对 | 在地下/山地伪装成石块，靠近时苏醒；镐伤害 ×2，其他武器 ×0.5 | 圆石、铁锭、6% 钻石 |
| **幽光灵**（原创） | 敌对 | 夜晚漂浮发光，照亮周围；绕圈后猛冲，日出时消散 | 幽光粉（4 个合成幽光灯） |

- 敌对生物在亮度 ≤ 7 的地方生成（夜晚地表或黑暗洞穴），火把能阻止附近刷怪
- **A\* 寻路**：生物会绕墙、跳台阶、走楼梯、避开岩浆；蜘蛛会规划爬墙路线，体型宽的生物会考虑 2×2 的通行空间；动物闲逛时会避开水和高崖；敌对生物看到或在 12 格内“听到”你后会持续追踪 8 秒，即使隔着墙也会绕路过来；卡住时会自动重新规划
- 近战攻击（剑伤害最高，下落时暴击 ×1.5）、击退、受伤闪红、死亡倒地
- 弓：按住右键蓄力、松开射箭；射出的箭可以捡回
- 饥饿值：疾跑/跳跃/挖掘/受伤消耗；满饱食度回血，饿到 0 掉血，低于 3 格不能疾跑
- 食物：生肉放进熔炉烤熟恢复更多；树叶偶尔掉苹果
- 暂停菜单可切换「和平」难度（不生成敌对生物）；创造模式按 G 可生成随机生物
- 生物会随存档保存（幽光灵除外，它们天亮就会消散）

## 用到的 Web 技术

| 技术 | 用途 |
| --- | --- |
| WebGL（Three.js） | 渲染，自定义 GLSL 着色器实现光照与雾 |
| Web Worker | 后台线程生成地形，不阻塞主线程 |
| IndexedDB | 保存世界（RLE 压缩修改过的区块）、背包、方块实体 |
| localStorage | 保存设置（渲染距离、视野、灵敏度、音量） |
| Pointer Lock API | 第一人称鼠标视角 |
| Web Audio API | 程序化合成挖掘、放置、脚步、受伤等音效 |
| Canvas 2D | 程序化绘制 16×16 像素贴图图集和等距方块图标 |

## 操作

| 按键 | 作用 |
| --- | --- |
| W A S D | 移动 |
| 空格 | 跳跃 / 游泳上浮（创造模式双击切换飞行） |
| Shift | 潜行（飞行时下降） |
| Ctrl / R | 疾跑 |
| 左键（按住） | 挖掘；点击生物为攻击 |
| 右键 | 放置方块 / 打开工作台、熔炉、箱子（潜行时强制放置） |
| 按住右键 | 吃食物 / 拉弓（松开射箭） |
| G | 创造模式：在面前生成随机生物 |
| 中键 | 选取方块 |
| 滚轮 / 1–9 | 切换快捷栏 |
| E | 打开背包（创造模式为物品选择） |
| Q | 丢弃 1 个手持物品（Ctrl+Q 丢弃整组） |
| F | 创造模式切换飞行 |
| F3 | 调试信息 |
| Esc | 暂停菜单（设置、切换模式、保存、退出） |

背包内：左键拿起/放下，右键拿一半/放一个，Shift+左键快速转移（盔甲会直接穿上）；手持物品**按住左键拖过多个格子平均分配**、**按住右键拖动每格放一个**；**双击**把同类物品收集成一组；鼠标悬停时按 **1–9** 与快捷栏交换、按 **Q** 丢出。

## 常用配方

| 产物 | 配方 |
| --- | --- |
| 木板 ×4 | 1 原木 |
| 木棍 ×4 | 2 木板竖排 |
| 工作台 | 2×2 木板 |
| 熔炉 | 8 圆石围一圈 |
| 箱子 | 8 木板围一圈 |
| 火把 ×4 | 煤炭在上、木棍在下 |
| 镐 / 斧 / 锹 / 剑 | 与原版相同（木板、圆石、铁锭、金锭、钻石 + 木棍） |
| 砂岩 / 石砖 | 2×2 沙子 / 2×2 石头 |
| 铁块/金块/钻石块 | 9 个锭（可拆回） |
| 弓 | 3 木棍 + 3 线（与原版相同） |
| 箭 ×4 | 燧石 / 木棍 / 羽毛 竖排（燧石来自沙砾） |
| 白色羊毛 | 2×2 线 |
| 幽光灯（原创） | 2×2 幽光粉，像火把一样发光 |
| 铁桶 | 3 个铁锭摆成 V 字形 |
| 打火石 | 铁锭 + 燧石（无序） |
| TNT | 5 火药 + 4 沙子交错摆放 |
| 头盔 / 胸甲 / 护腿 / 靴子 | 与原版相同（皮革、铁锭、金锭、钻石） |

熔炉：铁矿石→铁锭，金矿石→金锭，沙子→玻璃，圆石→石头，原木→煤炭，生猪排/牛肉/鸡肉/羊肉→熟食。

## 代码结构

```
src/
  main.js          菜单、设置、启动流程
  game.js          游戏主循环、输入、挖掘/放置、熔炉、存档
  world.js         区块流式加载、Worker 池、网格重建、方块实体
  terrain.js       地形/生物群系/洞穴/矿石/树木生成（在 Worker 中运行）
  worldgen.worker.js
  mesher.js        区块网格：面剔除、AO、平滑天空光、特殊形状方块
  materials.js     GLSL 着色器（天空光 + 火把光 + 雾）
  textures.js      程序化像素贴图图集
  icons.js         物品图标（等距方块 / 平面物品）
  blocks.js        方块与物品注册表、挖掘公式
  recipes.js       合成与冶炼配方
  player.js        玩家物理
  ui.js            HUD 与容器界面
  mesh.worker.js   后台线程：光照 + 网格构建
  fluids.js        水流模拟（每 0.25 秒一次更新）与水流方向
  fire.js          火焰蔓延/燃烧、岩浆点火、点燃的 TNT 实体
  fx.js            像素粒子（烟、火苗、岩浆火星）、环境发射器、着火实体的火焰
  lighting.js      天空光/方块光泛洪（区块 3×3 工作区）与动态光 3D 纹理
  items.js         掉落物实体（物理、吸取、合并、存档）
  mobs/pathfind.js 体素 A* 寻路（8 方向、跳一格、可下落 3 格）
  physics.js       生物的 AABB 碰撞、射线-包围盒检测
  mobs/models.js   方块拼装的生物模型 + 程序化生物贴图
  mobs/mob.js      生物属性表与 AI（游荡、逃跑、追击、射箭、爆炸、伪装、飞行）
  mobs/manager.js  刷怪/消失、战斗、箭、爆炸、存档
  sky.js hand.js particles.js audio.js storage.js raycast.js noise.js inventory.js
```
